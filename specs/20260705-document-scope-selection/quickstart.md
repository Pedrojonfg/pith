# Quickstart: Document Scope Selection

1. Upload a multi-chapter document.
2. After structure analysis, confirm **Scope selection** screen appears.
3. Choose **Full document** → mode select; inventory matches pre-feature behavior.
4. Select two non-contiguous chapters → confirm char count; enter any mode; inventory reflects scoped text only.
5. Open guide chat; ask about content outside scope → response includes `[OUT_OF_SCOPE]` prefix.
6. Enter Slow mode → scope screen skipped; Phase 0 shows fillable map / checkpoint toggles.
