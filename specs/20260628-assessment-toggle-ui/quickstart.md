# Quickstart: Assessment Toggle UI

1. Open any document → RSVP → Configure screen shows "Quick assessment before studying" (checked).
2. Uncheck → Generate blocks → no pre-packing assessment screens.
3. Check → Generate blocks → assessment appears.
4. Reload → toggle state matches last choice.
5. Switch to Questions/Slow → toggle hidden.
6. Run `node cursor-tests/20260628_assessment-toggle-ui.mjs`.
7. Run `node cursor-tests/20260606_validate-sw-update-flow.mjs` after SW bump.
