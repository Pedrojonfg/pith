# Quickstart: Vault Study Trail

1. Open app → Settings or Vault branch → Knowledge Vault overlay.
2. Select a concept with study activity (RSVP/Cloze/Review sessions closed to vault).
3. Scroll detail panel → **Study trail** collapsed at bottom with event count.
4. Expand → rows show mode, badge, relative time; newest first.
5. Select a concept with empty `observations` → empty state message.
6. Run `node cursor-tests/20260628_vault-study-trail.mjs`.
7. Run `node cursor-tests/20260606_validate-sw-update-flow.mjs` after SW bump.
